# Original six-component test bundle

This directory collects the non-clinical example files that were previously
distributed across the six CURE-NGS component repositories. Both official
CURE-NGS container variants include this directory. A user can copy it from a
downloaded image to an ordinary host folder without cloning the component
repositories:

```bash
mkdir -p tutorial-data
docker run --rm --user "$(id -u):$(id -g)" \
  --volume "$PWD/tutorial-data:/data/output" \
  ghcr.io/ncdcbioinformatics/cure-ngs-harmonizer:0.2.5-core \
  export-tutorial-data /data/output/component-test-data

# Or place the VCF and validated reference MAF directly into the exact
# manuscript/NCDC V1.3.3 folder layout:
docker run --rm --user "$(id -u):$(id -g)" \
  --volume "$PWD/tutorial-data:/data/output" \
  ghcr.io/ncdcbioinformatics/cure-ngs-harmonizer:0.2.5-core \
  export-v1.3.3-example /data/output/NGS_VCF
```

`manifest.json` records the byte size, SHA-256 digest, source repository, and
expected row count. `verify-tutorial-data` verifies the copy embedded in the
image before it is used.

## Component map

| No. | Component | Original input in `inputs/` | Included output or expectation |
| --- | --- | --- | --- |
| 1 | `panel_VCF_vcf2maf_pipeline` | `MSKCC_VCCF_test.zip`; extracted GRCh37 `test_b37.vcf` (25 variants) | `expected/test_b37.maf` (25 annotated rows) |
| 2 | `HGVS_to_minimal_MAF_pipeline` | `minimal_maf_test_normalized.xlsx` (2,625 rows) | `inputs/minimal_maf_from_hgvs_vep_V2.maf` (2,113 rows) |
| 3 | `minimal_MAF_to_annotated_MAF_pipeline` | `minimal_maf_from_hgvs_vep_V2.maf` | `expected/minimal_maf_from_hgvs_vep_V2.vcf2maf.maf` (2,054 annotated rows) |
| 4 | `gene_name_harmonization` | `gene_name_test.csv` (324 rows) | The file's `final_gene_name` column contains the expected symbols |
| 5 | `gene_fusion_normalizer` | `gene_split_test.csv` (274 rows) | Parsed smoke-test output is written by the beginner tutorial |
| 6 | `hgvs_normerlizer` | `hgvs_to_minimal_maf_test.xlsx` (2,625 rows) | `expected/minimal_maf_test_normalized.xlsx` is the historical normalized table |

The two annotated MAFs under `expected/` are historical reference outputs,
not files secretly generated by the reference-free core tutorial. They let a
new user see a real non-empty output immediately. Regenerating them requires a
separately mounted hg19/GRCh37 FASTA and matching VEP cache; those resources are
too large to commit or embed. Because VEP annotations change between releases,
compare coordinate/allele sets and recorded tool versions rather than assuming
byte-for-byte identity across different VEP releases.

## Provenance and privacy

- `MSKCC_VCCF_test.zip` and `test_b37.vcf` are public vcf2maf test fixtures.
  Their synthetic `TUMOR`/`NORMAL` sample labels are retained, and the
  applicable attribution is copied as `LICENSE.MSKCC-vcf2maf.Apache-2.0`.
- The spreadsheet and CSV inputs are the public test files already committed
  to the named NCDCbioinformatics component repositories.
- The MAF files were generated from those generic test inputs and contain only
  generic test identifiers.
- No CURE-NGS patient-level or institution-identifying data are distributed in
  this bundle.

The bundle is for software testing and manuscript reproduction only. It is not
a clinical reference dataset.
